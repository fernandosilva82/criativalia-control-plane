## AGENT PERFORMANCE ENGINE

### Each agent has performance state:

**Metrics:**
| Metric | Description |
|--------|-------------|
| success_rate | % of successful tasks |
| fail_rate | % of failed tasks |
| blocked_count | Times stuck |
| quality_score | Output quality |
| speed_score | Task completion speed |
| stability_score | Consistency |

### Actions based on performance:

**If agent fails often:**
- reduce priority
- assign supervisor
- request review

**If agent succeeds often:**
- increase priority
- assign more tasks
- trust decisions more
